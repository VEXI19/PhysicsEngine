# Physics Engine

Physics engine project crated as a part of engineering thesis: Automatic rocket control system, based on computer simulations and ar-
tificial intelligence algorithms by Dominik Kubciki and Jakub Kindlik

## Project set up

1. Download repo

    ```bash
    git clone https://github.com/VEXI19/PhysicsEngine.git <folder name> 
    cd <folder name>
    ```

2. Set up virtual environment

    ```bash
    python -m venv venv
    ```

3. Activate virtual environment

    #### Windows
    ```bash
    .\venv\Scripts\Activate.ps1
    ```
    #### Linux
    ```bash
    source venv\Scripts\activate
    ```

4. Install libraries

    ```bash
    pip install -r requirements.txt
    ```
