\abstractpage
{Tytuł: System automatycznego sterowania rakietą oparty na symulacjach komputerowych i algorytmach sztucznej inteligencji}
{Celem niniejszej pracy jest stworzenie systemu autonomicznego sterowania rakietą, który łączy silnik fizyczny z technikami
uczenia maszynowego. W ramach projektu opracowane zostały dwa główne moduły: moduł symulacji fizycznej oraz moduł uczenia maszynowego.
Moduł symulacji fizycznej obejmuje model dynamiki lotu rakiety, uwzględniający kluczowe siły i zjawiska fizyczne. Moduł uczenia maszynowego
implementuje system uczący oparty na algorytmie PPO. Eksperymenty wykazały, że połączenie modelu fizycznego z algorytmem uczenia
maszynowego pozwala na skuteczną naukę algorytmu sterującego, lecz również uwydatniły limitacje zastosowanego modelu fizycznego i .
Niemniej, system wykazuje zdolność do utrzymania stabilnego lotu pionowego. Praca otwiera perspektywy dla przyszłych
badań i rozwoju, w tym ulepszenia silnika fizycznego, testowania symulacji oraz dalszego dopracowywania algorytmu sterującego.}
{rakieta, symulacja, uczenie maszynowe, algorytmy sterujące, PPO}

{Title: Automatic rocket control system based on computer simulations and artificial intelligence algorithms}
{The aim of this thesis is to create an autonomous rocket control system that combines a physics engine with
machine learning techniques. The project consists of two main modules: the physical simulation module and the
machine learning module. The physical simulation module includes a model of rocket flight dynamics, taking into
account key forces and physical phenomena. The machine learning module implements a learning system based on the
 PPO algorithm. Experiments have shown that the combination of a physical model with a machine learning algorithm
allows for effective training of the control algorithm, but also highlights the limitations of the applied physical
model. Nevertheless, the system demonstrates the ability to maintain stable vertical flight. The work opens up
perspectives for future research and development, including improving the physics engine, testing simulations,
    and further refining the control algorithm.}
{rocket, simulation, machine learning, control algorithms, PPO}
